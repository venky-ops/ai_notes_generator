# 🧠 AI Notes Generator  
Convert rough notes into clean, structured, AI-generated Markdown notes.

## 🚀 Overview
The **AI Notes Generator** is an AI-powered tool that transforms messy or unformatted text into well-organized notes. It uses Hugging Face summarization models to extract key information, generate headings, bullet points, and summaries, and outputs neatly formatted Markdown.

This project is perfect for:
- Students preparing study material  
- Developers who write documentation  
- Content creators summarizing large text  
- Anyone who wants fast, clean, organized notes  

---

## ✨ Features
- Text cleaning and preprocessing  
- Automatic chunking for long content  
- AI-based summarization using Transformers  
- Auto-generated headings & bullet points  
- Markdown output  
- Optional Streamlit UI
